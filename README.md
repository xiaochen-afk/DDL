# DDL 生存指南

面向大学生的本地优先截止时间管理应用。它用“校园应急指挥台”的视觉与文案呈现任务、时间压力和下一步行动，让分散在课程群、课堂通知与备忘录里的 DDL 变得可见、可排序、可处理。

> 当前提供 **Android 预览版**。仓库包含 Flutter 的 iOS 工程，但尚无经过构建、签名和真机验收的 iOS 安装版本。

## 项目背景

学生面对的作业、考试、社团和生活事项常来自不同渠道。只把它们记进普通待办列表，仍会遇到几个问题：任务很多却不知道先做哪一个；只看截止日期，忽略完成任务所需的时间；重要但不紧急的事一直被推迟；错过截止时间后，任务长期挂在列表里，增加心理负担。

DDL 生存指南围绕三个问题设计：**现在先做什么、哪个截止时间最危险、已经逾期的任务如何结案**。应用结合截止时间、重要程度、预计耗时、近期任务密度和同类任务历史，给出可解释的风险排序；通过四象限与“忏悔录”把优先处理和逾期复盘接成一个完整流程。文案带有轻度游戏化表达，也允许调整危机文案强度。

项目采用本地优先方案：任务、偏好及相关记录保存在设备本机 SQLite，无需注册账号或连接云端服务。提醒由设备本地通知完成，不依赖远程推送。

## 当前功能

- **主页**：压力指数、未来三天的任务和高风险事项，支持快速查看与完成。
- **待办**：按动态四象限和风险分排序，提供时间筛选、任务详情、编辑、完成和删除确认。
- **创建任务**：设置截止时间、分类、重要度、预计耗时及备注；短截止任务可单独设置提前提醒。
- **逾期处理**：到期未完成的任务进入“忏悔录”，可记录为逾期完成或确认错过。
- **提醒设置**：本地通知、免打扰时段、默认提前量、通知权限及 Android 精确提醒状态。
- **个人中心**：本地资料、任务统计和危机文案强度设置。
- **本地持久化**：SQLite 存储任务、设置、事件与提醒记录，并包含现有数据库版本的前向迁移。

## Android 预览版

从仓库的 [Releases](https://github.com/xiaochen-afk/DDL/releases) 下载 APK，在 Android 设备上打开安装。安装时如系统提示“允许安装未知来源应用”，请按设备指引为当前文件管理器或浏览器授权。

当前 APK 使用开发调试密钥签名，仅用于预览和功能体验，**不是正式商店发布包**。后续若改用正式发布密钥签名，通常无法直接覆盖安装此预览版；安装正式版前请留意本机数据。当前尚无 JSON 导出、导入和云同步功能，卸载应用或清除应用数据会丢失本地记录。

提醒是否能在指定分钟送达，取决于通知权限、精确闹钟权限以及厂商后台省电策略。若未取得精确提醒权限，应用会使用非精确方式，通知可能延迟。vivo 设备上已完成部分通知对照验证；OPPO 及更多机型、锁屏与重启场景仍需继续验收。

## 技术实现

| 层次 | 实现 |
| --- | --- |
| 界面与应用逻辑 | Flutter、Dart |
| 本地数据 | SQLite、Repository |
| 风险计算 | 纯 Dart 规则引擎，按时间、重要度、工作量、密度和历史计算 |
| 系统提醒 | 本地通知、时区处理与平台通知权限 |
| 测试 | 领域逻辑、数据库迁移和主要界面交互测试 |

Android/iOS 客户端使用 SQLite；Web 仅作为开发预览，使用内存数据，不提供正式 Web 产品。项目不包含业务后端、账号系统或远程推送。

## 本地开发

需要安装与 `pubspec.yaml` 兼容的 Flutter/Dart SDK，以及 Android SDK。进入仓库根目录后运行：

```bash
flutter pub get
flutter run
flutter analyze
flutter test
flutter build apk --release
```

构建后的 APK 位于 `build/app/outputs/flutter-apk/app-release.apk`。当前 Android Gradle 配置的 `release` 构建仍采用 Debug 签名；面向正式用户分发前，必须配置并安全保存独立的正式签名密钥，完成升级、通知和数据迁移验收。
